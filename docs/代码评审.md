## 实施决策

- 使用独立公开仓库与功能分支，个人配置留在私有仓库；代价是旧 CLI 需要同步修复或迁移。
- registry 精确版本切换、来源迁移、自身更新保留为单独操作；代价是部分更新不能一键执行。
- daemon 归属通过实际父进程的祖先关系验证；查询失败时拒绝执行，Windows 的间接进程校验需要 PowerShell/CIM。
- 对异常中断不自动重放修改命令；原生入口可检查并解除已确认死亡的任务锁，归属不明的执行锁需人工检查。
- 本机系统 Node 曾因动态库更新暂不可用，使用 Codex 自带 Node 24.19.0 完成本地验证；最低 Node 22.18 的覆盖由 CI 补充。
