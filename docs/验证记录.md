## 兼容性与边界

真实 Windows daemon、Windows 客户端与第二台 Mac 尚未逐机接入验证；CI 的平台测试不能替代这些验证。插件本身没有后台自动跨主机广播，每台 daemon 需分别安装并指向自己的配置 checkout。

GitHub、Linear 等插件的登录认证不由配置一致性验证保证。registry 版本切换、来源迁移和自身更新需要独立处理。未记录的 npm 源码手工修改不属于通用源码备份范围，应显式记录补丁；Git 源码修改会阻止同步。

开发依赖来自官方 0.11.4 scaffold，npm 报告的上游开发依赖漏洞没有通过强制升级宿主 SDK/React Native 处理。插件没有需要下载安装的第三方运行时依赖。

开发期间系统 Homebrew Node 曾因动态库更新暂不可用，使用 Codex 自带 Node 24.19.0 完成本地验证，没有修改系统 Node 或动态库。最低 Node 22.18 的覆盖见公开 CI。
